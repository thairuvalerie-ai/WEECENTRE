# WEECENTRE

## Overview
**WEE Centre** (Waste Electrical and Electronic Equipment Centre) is an initiative dedicated to safe, environmentally friendly e-waste management, recycling, and hardware refurbishment. 

---

## Features
- **E-Waste Tracking:** Real-time logging and tracking of e-waste collection and disposal.
- **Equipment Refurbishment:** Workflow tools for testing, repairing, and repurposing hardware.
- **Environmental Impact Reporting:** Analytics and metrics on reduced carbon footprints and recycled materials.
- **Community Outreach & Booking:** Service booking portal for individuals and corporates to schedule e-waste pickups.

---

## Tech Stack
- **Frontend:** React / Next.js, HTML5, CSS3, Tailwind CSS
- **Backend:** Node.js, Express / Supabase
- **Database:** PostgreSQL / Supabase
- **Hosting/Deployment:** Vercel / GitHub Pages
